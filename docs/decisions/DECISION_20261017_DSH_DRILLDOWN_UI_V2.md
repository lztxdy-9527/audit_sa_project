# 决策记录：证据链下钻 UI v2（多页 + 单页 + Excel 单元格定位 + 图像占位）

记录编号：`DSH-SCOPE-20261017-04`。日期：2026-10-17（Asia/Singapore）。记录人：DSH Architect/Reviewer。依据：人类在本会话中的直接指示（原文见 §1）。

## 1. 人类授权原文（摘要）

> …希望双击能直接定位到 Excel 单元格，这最切合实务…如果数据量很大还能实现跳转和链接吗？…页面形式我希望多页跳转和单页逐层展开都做…只到结构化凭证字段，但是最好给发票回单这种原始凭证图像留一个占位空间…生成方式先用单独一条命令生成的形式来做。

## 2. 决定

**D-UI2-1 双击定位到 Excel 单元格的实操边界。** 浏览器**不能**命令 Excel 选中某个单元格。可行且稳定的做法是：生成一份**证据链底稿 .xlsx**，其中的金额/凭证号等可点单元格带**超链接**，直接定位到同一工作簿内"原始表行"页的对应单元格（数据从原表行复制并保留原值）。同时提供"打开原始 Excel 文件"的超链接（只打开文件，不定位单元格）。说明须如实写：**Excel 中单击超链接即定位；双击是进入单元格编辑**，不是触发链接。外链到原始工作簿单元格的写法因 Excel 版本/信任设置而异，本轮不承诺。

**D-UI2-2 双形态页面。** 同一次生成同时产出：
1. **多页跳转版**（问题清单 → 账务行 → 凭证 → 原始表行，面包屑返回）——适合快速追溯、小屏幕/出差笔记本；
2. **单页比对版**（一条事项的线索、台账、凭证、原始表行同页，使用原生 `<details>` 折叠、无脚本）——适合逐格比对与打印。

**D-UI2-3 凭证边界与图像占位。** 只到**结构化凭证字段**；发票/回单影像本轮不接。HTML 与 Excel 均保留**图像占位区**，标注"模拟数据，当前无对应真实凭证图像"，并预留将来放图的固定位置与字段（发票号/回单号/日期/金额）。

**D-UI2-4 生成方式。** 先用**单独命令**生成（`build_trace_index.py` → `build_drilldown_site.py` → `build_excel_workbook.py`），不并入演示主流程；稳定后再评估自动化。

**D-UI2-5 大数据量设计。** 跳转与链接本身不随数据量退化；退化的是生成时间与单页渲染。因此：
- 索引与页面**按事项分页**（默认 50 条/页），每条事项一页，不做全量单页；
- 单页比对版只放**该事项的切片**（台账行/凭证/原表行），不放全表；
- Excel 底稿只放**事项切片**并定位到"原始表行"页；
- 规模上限与实测耗时必须如实登记，不做无依据的"任意大数据"承诺。

**D-UI2-6 语言红线（审计人员使用）。** 可见文本只用财务/审计语言（金额、应付单、付款、退款、分摊、发票、合同、回单、审批单、入库单、差异、未取得、来源工作表/行/列、核对结论）；禁止出现 JSON/接口/哈希/脚本/字段类型等技术词；技术身份信息收进默认折叠的"资料接收记录"，不进入主视图。

## 3. 边界

`real_approval=null`、真实初判未保存、0008、`next_step_allowed=false`、`ai_enabled=false`；全部合成数据；UI 只读展示既有证据，不修改、不计算新数、不产生审计结论；不接影像/OCR、不做外部查验、不采集人类核对结论。看板不变，`done` 由人类办理。
