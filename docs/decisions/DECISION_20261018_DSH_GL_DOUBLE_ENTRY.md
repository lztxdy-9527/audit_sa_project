# 决策记录：借贷记账法核对（GL v1）——新增总账输入与六类核对

记录编号：`DSH-SCOPE-20261017-06`。日期：2026-10-18。记录人：DSH Architect/Reviewer。依据：人类明确要求"我要做真正的借贷记账法核对，只有这样才符合实务"；并据《会计基础工作规范》第63条（账证/账账/账实核对，含记账方向）与试算平衡、应付账款实质性程序（明细表、借方余额分析与重分类、函证、期后付款）修正方案。

## 1. 决定

**D-GL-1 新增独立输入包 GL v1。** 现有 `task043` 输入（凭证附件 + 银行流水）不变；新增 `data/evidence_inputs/gl_v1/`，包含：科目表、记账凭证（借贷分录）、科目余额表（期初/本期发生/期末）、总账、明细账（三栏式）、报表摘录、银行对账单、银行日记账、附件索引、清单（manifest）。合成数据，明确标注，不是真实账套。

**D-GL-2 六类核对（借贷记账法口径）。**
1. **凭证平衡**：逐张"有借必有贷、借贷必相等"，期间借贷合计相等；
2. **试算平衡**：科目余额表期初/本期/期末借贷两两相等；逐科目"期初 + 借方发生 − 贷方发生 = 期末余额"（按方向）；
3. **账证**：明细账/总账发生额与记账凭证按科目汇总一致（含借贷方向）；
4. **账账**：总账余额与明细账合计一致；
5. **账表**：科目余额表与报表项目一致（含应付借方余额 4,000 的重分类列示）；
6. **账实**：银行日记账与银行对账单一致，并编银行余额调节表（期初 + 收入 − 支出 = 期末；列未达账项）。

**D-GL-3 合成样本口径（与既有业务单据勾稽）。** 4 张凭证、4 个科目（库存商品、应付账款、银行存款、实收资本）；应付 AP01 5,000；付款 P01/P02 各 5,000；退款 R01 1,000；期末应付**借方 4,000**（多付/预付，报表重分类为预付 4,000）；银行存款期初 20,000、期末 11,000；试算平衡借方合计 = 贷方合计 = 20,000。

**D-GL-4 边界。** 全部合成；不做函证/监盘/外部查验；不接 AI/终判；人类结论由人填写；核对结果只展示证据与差异，不构成审计结论；真实批准 `null`、真实初判未保存、0008、`next/AI=false`。
