# 证据链底稿 .xlsx 指南（全量 + 自动筛选 + 可点击定位）

标识：`TASK-050-workbook-1.1`。实现：`scripts/build_excel_workbook.py`（项目既有 openpyxl）。
输入：TASK-048 索引 v1.1；输出：`证据链底稿.xlsx`（六个工作表，全量行 + 状态列 + 自动筛选）。

## 1. 用法

```powershell
.venv\Scripts\python.exe -B scripts\build_excel_workbook.py `
  --index data\runtime_initial_judgment_recording_tests\task051_index_01\trace_index.json `
  --out-dir data\runtime_initial_judgment_recording_tests\task051_workbook_01
```

`--out-dir` 必须从未存在、位于测试根下、以 `task050_` 或 `task051_` 开头。
退出码：`0` 成功；`1` 索引不完整/引用不闭合（字段精确）；`2` 参数/路径错误。

## 2. 工作簿结构

1. 说明：边界横幅；"单击带下划线的金额或凭证号可定位…双击是进入单元格编辑，不会触发链接"；
   打开原始工作簿超链接；资料接收记录；**备份纪律**（源只留存一份、生成不复制源、每次只新增小文件、
   项目内不删除旧证据）。
2. 问题清单：每条事项一行，金额（元/分）与定位链接指向《原始表行》对应单元格，涉及账务/凭证链接。
3. 台账明细：**全量**账务行（应付/付款/退款/分摊），每字段一行；状态列；来源列；"查看原行"。
4. 原始表行：**全量**四张表数据行（9 行），状态列（已涉及/未涉及），涉及单元格高亮。
5. 凭证：**全量** 8 张，状态列（已取得/未取得）；缺证写"未取得"。
6. 图像占位：需影像凭证一行（发票/银行回单），占位说明与预留放置位置。

## 3. 规则

- 数值只复制不重算；元=分/100（两位小数），分整数并列。
- 链接：内部 `#'Sheet'!Cell` 目标必须存在；外部仅"打开原始工作簿"；测试逐条校验。
- **自动筛选**：台账明细/凭证/原始表行均设置 `auto_filter` 覆盖表头数据区；表头冻结、列宽、A4 横向。
- 语言：可见文本只用审计语言；技术身份只出现在《说明》最小字段。
- 确定性：同一输入两次生成字节相同（固定打包时间与核心属性）。

## 5. 边界

不接入演示；不生成页面（TASK-049 已有）；工作簿只读展示既有合成证据，不证明凭证/流水真实，
不构成审计结论；核对结论由审计人员填写。

## 6. 审阅合并后的底稿（TASK-052）

`apply_review_notes.py` 用合并索引重新生成站点与底稿：底稿保持全量行、状态列与自动筛选；
审阅状态/问题/建议/审阅人/日期在《审阅记录.xlsx》中集中登记（列：编号/事项或记录/审阅状态/
审计问题描述/建议处理/审阅人/审阅日期/对应资料版本/审阅记录版本），不覆盖原底稿与机器证据。

## 7. 借贷核对页（TASK-057，索引含 `gl` 时）

底稿新增七页：《科目余额表》《记账凭证》《总账》《明细账》《账表核对》《银行调节》《核对结果》：

- 表头冻结、自动筛选、金额元/分并列（分整数、元两位小数）；应付 4,000 借方行高亮；
- 《记账凭证》逐行借贷与附件编号、关联账务；《账表核对》含应付借方重分类说明；
  《银行调节》含期初/收入/支出/期末与未达账项笔数；《核对结果》列六类 + 附件状态与差异数。
- 《说明》补“借贷核对为合成账套演示”；索引无 `gl` 节时不生成这七页（旧行为不变）。
