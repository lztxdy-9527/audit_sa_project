## 3. 页面结构（两种形态，同一次生成）

**A. 多页跳转版（适合快速追溯、小屏）**
```
index.html / index-<n>.html        问题清单（默认 50 条/页；红/黄/绿标记；金额可点）
case-<case_id>.html                事项详情：差异金额、差异原因、涉及账务、凭证清单、下一步提示
ledger-<type>-<id>.html            账务行：逐字段值 + 来源（工作表/第几行/第几列/原值）
voucher-<voucher_id>.html          凭证字段 + 来源记录 + 图像占位区
source-<sheet>-<row>.html          原始表行：该行各列原值，高亮本次涉及列；“打开原始 Excel 文件”链接
```
- 每页顶部：面包屑（问题清单 › 事项 › 账务行 › 凭证 › 原始表行）+ 返回上一层；底部：上一页/下一页事项。
- 页间全部相对链接；无外链、无 `<script>`、无 `<img>`（图像占位用 CSS 框）。

**B. 单页比对版（适合逐格比对/打印）**
`compare-<case_id>.html`：同一事项的**线索、台账行、凭证字段、原始表行**同页并列（上下分区，`<details>` 折叠；无脚本），可打印 A4。

## 4. 语言与视觉规则（硬性）

- 可见文本只用审计语言：金额（元/分并列）、应付单、付款、退款、分摊、发票、合同、银行回单、审批单、入库单、差异、未取得、来源工作表/行/列、核对结论。
- **禁止出现**（可见文本，标签剥离后检查）：`JSON`、`hash`、`SHA`、`API`、`script`、`pipeline`、`解析`、`字段类型`、`字节`、`编码`、`版本号`。
- 颜色只表达审计含义：`red`=差异/未取得、`yellow`=待核查线索、`green`=已核对一致；金额差异同时给出"应为/实为/差额"。
- 核对结论列：固定写"由审计人员填写"，不采集、不虚构。
- 图像占位：每张发票/回单一个灰色占位框，标注"模拟数据，当前无对应真实凭证图像"，并列出预留字段（单号/日期/金额）。
- 顶部固定边界横幅："合成数据；不是批次批准；不是审计结论；资料版本以资料接收记录为准"。
