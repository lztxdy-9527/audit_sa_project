## 3. 工作簿结构（文件名 `证据链底稿.xlsx`）

1. **说明**：合成/边界横幅；使用说明——"**单击带下划线的金额或凭证号可定位到《原始表行》对应单元格；双击是进入单元格编辑，不会触发链接**"；"打开原始工作簿"超链接（指向原 Excel 文件）；"资料接收记录"（仅写接收日期/资料名称/份数，不写技术术语）。
2. **问题清单**：每条事项一行——编号、事项、类别、严重程度（红/黄/绿底色）、金额（元）、金额（分）、应为、实为、差额、涉及账务、凭证、状态、**定位链接**（指向《台账明细》或《原始表行》对应单元格）。
3. **台账明细**：事项涉及的账务行（应付/付款/退款/分摊），每字段一行或一列；含来源列（工作表/第几行/第几列/原值）、金额（分）与金额（元）；每行"查看原行"超链接指向《原始表行》对应单元格。
4. **原始表行**：事项涉及的原表行副本（工作表名 + 行号 + 各列原值），本次涉及的单元格用底色高亮；列宽/冻结表头便于比对。
5. **凭证**：凭证字段（发票/合同/回单/审批/入库）+ 来源记录 + 图像占位列（"模拟数据，当前无对应真实凭证图像"）。
6. **图像占位**：每条需影像的凭证一行——凭证类型、单号、日期、金额、占位说明、预留放置位置（列宽留空，便于将来贴图）。

## 4. 规则

1. **数值只复制不重算**：金额/差异/合计取自已接受索引；元 = 分/100（两位小数），分列保持整数，二者并列显示。
2. **链接**：所有内部超链接使用 Excel 内部定位语法 `#'Sheet'!Cell`，目标页/单元格必须真实存在；测试逐条解析校验；除"打开原始工作簿"外**不允许任何外链**。
3. **语言**：可见文本只用审计语言；禁止 JSON/hash/SHA/API/script/pipeline/解析/字段类型/字节/编码 等词；技术身份只出现在《说明》最小字段。
4. **格式**：表头冻结、列宽、数字格式（元 `#,##0.00`、分 `#,##0`）、严重程度底色、金额列加粗/下划线提示可点；A4 横向打印设置。
5. **确定性**：同一输入两次生成，工作簿的单元格值、超链接目标、格式类别完全一致；若字节不一致（xlsx 内含打包元数据），须在回执如实说明并以"语义一致"为准，不得声称字节相同。
6. **规模**：用 TASK-048 的 **200 条事项**夹具生成，登记行数、文件大小、生成耗时与链接完整性；Excel 只放事项切片，不复制全表。
