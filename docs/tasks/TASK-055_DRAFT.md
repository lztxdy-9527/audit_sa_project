## 3. 契约校验（`gl_input_contract_v1.py`）

CLI：`--gl-root data/evidence_inputs/gl_v1`；退出码 `0` 通过、`1` 内容不合法（精确字段）、`2` 参数/路径错误。

必须校验：
1. 文件齐全、JSON 可解析、版本 `gl-1.0`、期间与批次绑定；
2. manifest 逐文件长度/SHA 与实际一致（自身除外）；
3. 科目引用存在；金额为整数分；`debit`/`credit` 恰一非零；
4. 每张凭证借贷相等（逐张）、期间借贷合计相等；
5. 科目余额表：期初/本期/期末借贷两两相等；逐科目 `期初 + 借 − 贷 = 期末`（方向）；
6. 总账/明细账：发生额与余额方向合法；明细账合计 = 总账余额；发生额 = 凭证按科目汇总；
7. 报表：资产合计 = 负债 + 权益；应付借方 4000 重分类为预付 4000；
8. 银行：对账单期末 = 期初 + 收入 − 支出；日记账与对账单三笔一致；附件引用存在且类型匹配。

任一项不符 → `exit 1` 且输出 `{code, field, expected, actual}`；不修复、不兜底。
