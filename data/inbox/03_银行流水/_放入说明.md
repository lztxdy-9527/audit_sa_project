# 03 银行流水：放入说明

## 放什么

`bank_transactions.json`：银行对账单流水（与银行回单对应）。

## 命名

`bank_transactions.json`（固定文件名，不要改名）。

## 必填字段

- `period`：`period_start`、`period_end`（`YYYY-MM-DD`）；
- `account`：账户名称；
- `opening_balance_cents`：期初余额（整数分）；
- `transactions[]`：每笔 `date`、`direction`（`IN` 收入 / `OUT` 支出）、`amount_cents`（整数分）、
  `reference`（银行参考号）。

## 示例

```json
{"date": "2026-09-10", "direction": "OUT", "amount_cents": 500000, "reference": "B001"}
```

## 校验

状态页检查 JSON 可解析、日期格式、方向为 `IN/OUT`、金额为整数分。
不符 → **需校验**；不修数据、不补默认值，整包退回。正式核对时与付款/退款逐笔比对。
