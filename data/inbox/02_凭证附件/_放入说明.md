# 02 凭证附件：放入说明

## 放什么

- 每张凭证一个 `.json` 文件：发票（INVOICE）、合同（CONTRACT）、银行回单（BANK_RECEIPT）、
  审批单（APPROVAL）、入库单（GOODS_RECEIPT）。
- `index.json`：列示全部凭证编号、类型、金额（分）与日期。

## 命名

- `index.json`；
- 凭证文件 `V-INV-<编号>.json`、`V-CTR-<编号>.json`、`V-BR-<编号>.json`、
  `V-APR-<编号>.json`、`V-GR-<编号>.json`（与 `index.json` 的编号一致）。

## 必填字段

- `index.json`：`vouchers[]`，每项 `voucher_id / voucher_type / amount_cents / date`。
- 凭证文件：`voucher_id`、`voucher_type`、`amount_cents`（整数分）、`date`（`YYYY-MM-DD`）；
  发票附 `invoice_no`，合同附 `contract_no`，回单附 `receipt_no`，审批附 `approval_no`，
  入库附 `gr_no`。

## 示例

```json
{"voucher_id": "V-INV-0001", "voucher_type": "INVOICE",
 "amount_cents": 500000, "date": "2026-09-05", "invoice_no": "INV-2026-0001"}
```

## 校验

```powershell
.venv\Scripts\python.exe -B scripts\build_intake_guide.py --intake-root data\inbox --out-dir data\runtime_initial_judgment_recording_tests\task058_status_01
```

状态页会检查 `index.json` 可解析、引用文件存在、金额为整数分；不符 → **需校验**，
不修数据、不补默认值，整包退回。
